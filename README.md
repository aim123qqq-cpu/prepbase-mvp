# SA HALPER

Статический frontend для подготовки системного аналитика: база знаний, вопросы и задачи подготовки без backend и серверной БД.

## Что уже есть

- темы подготовки;
- задачи по темам;
- база вопросов;
- статусы знания: `Не знаю`, `Учу`, `Знаю`, `Повторить`;
- поиск по вопросам, ответам и тегам;
- фильтр по теме и статусу;
- иерархическая база знаний из открытых источников;
- редактирование задач и вопросов;
- сохранение данных в `localStorage` браузера.

## База знаний

Иерархия хранится отдельно в `knowledge-tree.js`: домен → раздел → понятие → уточнение. Это временный фронтенд-слой данных, который потом можно перенести в API или базу без переписывания интерфейса.

Сейчас дерево покрывает интеграции, HTTP/API, требования, BPMN/UML, SQL, базы данных, DWH/ETL, архитектуру, безопасность и тестирование. У узлов есть ссылки на открытые источники: MDN, GraphQL Learn, OpenAPI, OMG BPMN/UML, PostgreSQL docs, Microsoft Learn, AWS, IIBA, Agile Alliance, Martin Fowler и Microservices.io.

## Как открыть

Откройте файл `index.html` в браузере.

## Парсинг вакансий hh.ru

Парсер навыков подготовлен и запускается через GitHub Actions раз в 2 часа, но продуктовые блоки вакансийной аналитики сейчас отключены от `index.html` до получения стабильного HH-доступа.

Секреты хранятся только в GitHub Actions:

- `HH_ACCESS_TOKEN` — предпочтительный вариант: токен приложения из `dev.hh.ru/admin`;
- `HH_CLIENT_ID` и `HH_CLIENT_SECRET` — резервный вариант: парсер получит токен приложения на время запуска;
- `HH_USER_AGENT` — переменная Actions, можно указать контакт приложения, например `prepbase-mvp/0.1 (email@example.com)`.

В коде не должно быть токенов, client secret или персональных ключей. Для масштабирования лучше завести отдельное приложение hh.ru под этот парсер, чтобы его токены не пересекались с другими сервисами.

Парсер также собирает `companyStats`: компании, количество открытых неархивных вакансий, роли, регионы, навыки, период публикаций и URL логотипа из hh.ru. Количество компаний в выдаче ограничивается переменной `COMPANY_STATS_LIMIT`, по умолчанию `50`.
