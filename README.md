# Prepbase MVP

Минимальный прототип приложения для подготовки к собеседованиям без трекинга самих интервью.

## Что уже есть

- темы подготовки;
- задачи по темам;
- база вопросов;
- статусы знания: `Не знаю`, `Учу`, `Знаю`, `Повторить`;
- поиск по вопросам, ответам и тегам;
- фильтр по теме и статусу;
- редактирование задач и вопросов;
- экспорт и импорт базы в JSON;
- сохранение данных в `localStorage` браузера.

## Как открыть

Откройте файл `index.html` в браузере.

## Следующие итерации

1. Редактирование тем подготовки.
2. Повторение вопросов по расписанию.
3. Авторизация и облачная база данных.
4. AI-помощник для генерации вопросов и улучшения ответов.
5. Режим тренировки: случайные вопросы и самооценка ответа.
