# SA HALPER Documentation

Документация фиксирует текущее состояние MVP: статический frontend без backend, база знаний и вопросы в JS-файлах, пользовательское состояние в `localStorage`, вакансийный парсер в коде, но продуктово скрыт до готового HH-доступа.

## Карта документов

- [Архитектура](architecture.md) - как устроен проект, runtime, deployment и поток данных.
- [Модель данных](data-model.md) - текущая "БД": `localStorage`, seed-файлы и payload аналитики.
- [Регламент обновления](maintenance.md) - что проверять раз в неделю и как поддерживать артефакты актуальными.

## Текущий статус

| Область | Состояние |
| --- | --- |
| Hosting | GitHub Pages, статические файлы из `main` |
| Backend | Отсутствует |
| Основное хранилище | `localStorage` браузера |
| Справочники | `seed-data.js`, `knowledge-tree.js`, `questions-extra.js`, `skills-stats.js` |
| База знаний | Активна, дерево с раскрытием/сворачиванием и сортировкой корневых блоков |
| Вопросы и задачи | Активны, редактируются в браузере |
| Вакансийная аналитика | Код и GitHub Actions есть, frontend-файлы сейчас не подключены к `index.html` до получения HH-токена |
| Логотип | `assets/sah-logo-v3.jpg` |

## Быстрый запуск

```bash
node dev-server.js
```

После запуска сайт доступен на `http://localhost:4173/`.

Если сервер не нужен, проект можно открыть как статическую страницу через `index.html`, но для проверки путей к ассетам предпочтительнее локальный HTTP-сервер.
